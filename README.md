# Neontron: Night Assault

Yandex Games top-down action. RU + EN.

## Quick start

```bash
npm install
npm run dev
```

```bash
npm run build
npm run check:i18n
npm run check:budget
npm run pack:yandex
```

Output zip: `release/neontron-yandex.zip`
