# Геймдизайн-документ: «СИГНАЛ»

**Жанр:** top-down action / combat puzzle  
**Платформа:** Яндекс Игры (mobile + desktop, portrait + landscape)  
**Возрастной рейтинг (целевой):** 12+ (стилизованное насилие)  
**Рабочее название:** СИГНАЛ  
**Версия документа:** 1.0  
**Дата:** 16.07.2026  
**Статус:** продуктовый диздок для производства MVP и заработка на Яндекс Играх

> Это **не** клон Hotline Miami и не использование чужого IP. Это игра с тем же **ядром удовольствия**: короткие жестокие вылазки, one-hit death, планирование маршрута, саундтрек как наркотик, мгновенный рестарт. Всё адаптировано под веб, тач и правила Яндекс Игр.

---

## 1. Продуктовая цель

### 1.1. Главные цели

1. **Увлекать** — игрок застревает в цикле «зашёл → умер → сразу рестарт → ещё один идеальный забег».
2. **Приносить прибыль** — устойчивый ARPU через рекламу SDK + rewarded + in-app, без paywall на прогресс.
3. **Пройти и удержать публикацию** — полное соответствие [требованиям Яндекс Игр](https://yandex.ru/dev/games/doc/ru/concepts/requirements), рейтинг каталога стабильно **> 30**.

### 1.2. Success metrics (после релиза)

| Метрика | Цель MVP (неделя 2–4) | Цель зрелой версии |
|---|---|---|
| D1 retention | ≥ 28% | ≥ 35% |
| D7 retention | ≥ 10% | ≥ 15% |
| Session length | 6–12 мин | 8–15 мин |
| Sessions / DAU | ≥ 2.0 | ≥ 2.5 |
| Ad eCPM-сессии с ≥1 interstitial | ≥ 70% | ≥ 80% |
| Rewarded opt-in rate | ≥ 18% | ≥ 25% |
| Paying conversion | ≥ 1.5% | ≥ 3% |
| Catalog rating | ≥ 4.2 / >30 балл платформы | ≥ 4.4 |
| Crash-free sessions | ≥ 99% | ≥ 99.5% |

### 1.3. Позиционирование в каталоге

**Одно предложение для карточки:**  
«Короткие ночные рейды: зайди, зачисть этаж, не умри. Один удар — и всё сначала.»

**Жанровые теги:** Экшен, Аркада, Шутер, Пиксель  
**Не позиционировать как:** симулятор жестокости, horror, политический триллер.

**Конкурентное преимущество на Яндекс Играх:**
- почти нет качественных «hotline-like» с нормальным тач-управлением;
- очень короткий time-to-fun (первый бой за 20–40 секунд);
- идеально ложится на interstitial между уровнями;
- высокий skill ceiling → органика, клипы, повторные заходы.

## 2. Высокоуровневая концепция

### 2.1. Сеттинг

Город **Нью-Рэйл** — неоновый портовый район, где по ночам на пейджер приходит **Сигнал**: координаты, время, задача. Игрок — безымянный исполнитель без имени и биографии на старте. Каждый уровень — адрес. Каждый адрес — головоломка из камер, патрулей и дверных проёмов.

Сюжет подаётся **коротко и холодно**:
- экран пейджера перед миссией (2–4 строки);
- после миссии — искажённый голос / текстовый лог;
- раз в главу — кат-сцена 10–20 секунд (без YouTube, только локальные ролики/таймлайн в игре).

Никакой политики, религии, реальных войн, реальных брендов, детей, животных как жертв.

### 2.2. Core fantasy

> «Я — тень в неоне. Одна ошибка — смерть. Один идеальный маршрут — катарсис.»

### 2.3. Столпы дизайна (pillars)

1. **Смерть = обучение, не наказание.** Рестарт < 0.4 сек. Нет длинных загрузок.
2. **Уровень = головоломка с оружием.** Победа через маршрут и тайминг, не через «больше ХП».
3. **Ритм и саунд.** Темп боя синхронизирован с музыкой; звук — часть геймплея.
4. **Mobile-first precision.** Тач не «урезанный ПК», а отдельный язык управления.
5. **Честная монетизация.** Реклама в паузах, RV только как бонус, покупки — косметика и комфорт.

### 2.4. Почему не «полный Hotline» на вебе

Классический Hotline Miami опирается на мышь + клавиатуру и жёсткий gore. На Яндекс Играх это убивает:
- конверсию на мобиле;
- модерацию / возрастной охват;
- удержание казуальной аудитории каталога.

Поэтому продукт делает **тот же дофамин**, но в формате **стилизованного combat-arcade** под 12+.

## 4. Геймплей

### 4.1. Основной игровой цикл (30–90 секунд)

```
Выбор миссии → брифинг 3 сек → заход в локацию
→ разведка / движение → цепочка убийств / нокаутов
→ ошибка = смерть → мгновенный рестарт
→ идеальная зачистка → выход → оценка ранга → награда
→ (опционально RV / interstitial) → следующая миссия / мета
```

### 4.2. Правила боя (core combat)

- Игрок и враги умирают / выходят из строя **с одного точного попадания** (или захвата сзади).
- Нет полоски HP у игрока в обычном режиме.
- Враги имеют конусы зрения и слух (шаги, выстрелы, разбитые объекты).
- Оружие подбирается с пола / снимается с врага; часть одноразовая (дробовик 1–2 выстрела).
- Тела/отключённые враги — препятствия и инструмент (толкнуть в другого, закрыть обзор).
- Победа: все цели миссии + выход в точку эвакуации.
- Поражение: любой контакт/выстрел по игроку, если нет i-frame от спецабилки.

### 4.3. Типы миссий

1. **Зачистка** — нейтрализовать всех.
2. **Цель** — нейтрализовать VIP, можно игнорировать часть патруля.
3. **Извлечение** — найти предмет / данные, выйти живым.
4. **Тишина** — лимит шума / запрет огнестрела (бонус к рангу).
5. **На время** — таймер; для daily/weekly.

Микс держит сессии свежими и даёт поводы для daily challenges.

### 4.4. Система рангов (skill loop)

После миссии:

| Ранг | Условие (пример) | Награда |
|---|---|---|
| C | прошёл с ≥3 смертями | база XP |
| B | ≤2 смерти, время среднее | XP + валюта |
| A | ≤1 смерть, хороший темп | XP + валюта + материал маски |
| S | 0 смертей + полный комбо/стиль | премиум-валюта (мало) + косметика-шанс |
| S+ | S + доп. условие миссии | уникальный шильдик / лидерборд |

Ранг — главный двигатель реиграбельности и «ещё один забег».

### 4.5. Враги (MVP набор)

| Архетип | Поведение | Контрплей |
|---|---|---|
| Патрульный | маршрут, узкий конус | обход, захват сзади |
| Щитовик | фронт неуязвим | заход в спину / взрывчатка |
| Дрогган | дробовик, короткая дистанция | не заходить в дверь в упор |
| Снайпер коридора | длинный узкий луч | дым / отвлечение / рывок |
| Пёс-дрон (робопёс) | слышит лучше, не «животное-жертва», а техносилуэт | приманка, тихий проход |
| Командир | поднимает тревогу рацией | приоритетная цель |

Тревога имеет стадии: подозрение → поиск → полный аларм. Полный аларм не всегда = fail, но сильно усложняет уровень.

### 4.6. Оружие и инструменты

**Ближний бой:** кастет, бита, нож, шокер (стан).  
**Дальний:** пистолет, УЗИ, дробовик, одноразовый арбалет.  
**Утилиты:** бросок предмета (отвлечение), осколок стекла, эми-граната (награда/RV/покупка за софт-валюту).

Баланс: огнестрел сильный, но шумит и привлекает. Нож тихий, но требует позиционки.

### 4.7. Маски / роли (мета-прогрессия)

Вместо копирования чужих масок — **«Личины»**: цифровые личности исполнителя.

Примеры MVP:
- **Личина «Искра»** — старт рывка короче кулдаун.
- **Личина «Глушитель»** — первый выстрел за миссию тише.
- **Личина «Стеклянный»** — видит конусы зрения врагов дольше.
- **Личина «Хирургия»** — захват сзади быстрее.
- **Личина «Кассета»** — +10% к очкам стиля (косметико-скоринговая).

Правила:
- Личины **не ломают** возможность пройти сюжет без доната.
- Сильные эффекты — маленькие; основное преимущество всегда в навыке игрока.
- Новые личины открываются сюжетом, S-рангами, ивентами, магазином (косметика + мелкие перки).

## 5. Структура контента

### 5.1. Кампания MVP

- **Пролог:** 3 туториал-миссии (обучение без стен текста).
- **Глава 1 «Район Плат»:** 8 миссий.
- **Глава 2 «Порт»:** 8 миссий.
- **Глава 3 «Крыша Сигнала»:** 6 миссий + финал.
- **Итого:** ~25 миссий основного пути.

Целевое время первого прохождения сюжета: **45–90 минут** чистого геймплея (с смертями — больше).  
Требование платформы «>10 минут основного содержания» закрывается с запасом.

### 5.2. Пострелизный контент (удержание)

1. **Daily Signal** — 1 процедурно смешанная миссия каждый день.
2. **Weekly Contract** — набор из 3 миссий на общий счёт.
3. **Моды сложности:** «Без HUD», «Только нож», «Перманентная тревога».
4. **Новые главы** раз в 3–4 недели (обновления сохраняют концепцию — требование 1.24).
5. **Сезонные скины личин / оружейные окрасы**.

### 5.3. Карта прогресса (мета-экран)

Не открытый мир. Это **вертикальный список районов / этажей** в стиле пейджера:
- миссии;
- % S-рангов;
- ежедневка;
- магазин;
- лидерборд друзей/глобальный (через лидерборды Яндекс Игр, если доступны / свой на облачных сейвах).

## 6. Управление

### 6.1. Mobile (обязательный стандарт)

**Рекомендуемая схема A — twin-stick + action buttons (основная):**
- левый стик — движение;
- правый стик — направление взгляда/стрельбы;
- кнопка A — атака / выстрел;
- кнопка B — взаимодействие / подбор / бросок;
- свайп двумя пальцами или кнопка — пауза.

**Схема B — tap-to-dash (для казуалов, опционально в настройках):**
- тап по врагу в ближнем радиусе = атака в его сторону;
- тап по полу = движение;
- долгое нажатие = прицел огнестрела.

Требования UX:
- кнопки ≥ 48–56 dp, отступы от краёв;
- зона стиков не перекрывает критический геймплей-центр;
- учёт sticky-banner: безопасные отступы UI;
- one-hand play на portrait (требование 1.10.4);
- longtap не вызывает контекстное меню браузера (`user-select: none`, `touch-action` и т.п.).

### 6.2. Desktop

- WASD / стрелки — движение;
- мышь — направление;
- ЛКМ — атака;
- ПКМ / E — взаимодействие;
- R — бросок;
- Esc — пауза.

Запрещены хоткеи ОС/браузера (Ctrl+W, Alt+F4, Ctrl+Tab и т.д. как игровые).

### 6.3. Обучение

Первые 90 секунд:
1. Движение.
2. Тихий захват.
3. Конус зрения.
4. Смерть и мгновенный рестарт как фича («Ошибка — часть плана»).
5. Подбор оружия.

Без модальных простыней. Только контекстные подсказки ≤ 1 строки.

## 7. Арт, звук, тон

> **Визуальные референсы:** см. пакет [docs/visual-style/](./visual-style/README.md)  
> (key art, top-down геймплей, личины, dissolve VFX, UI пейджера, палитра)

### 7.1. Визуальный язык

- Top-down, читаемые силуэты.
- Неон: пурпурно-циановые акценты **не как дефолтный AI-gradient UI**, а как свет локаций (вывески, дождь, мокрый асфальт).
- Пиксель/ретро-HD — выбранный стиль пакета референсов; не смешивать с фотореализмом.
- Игрок: тёмный силуэт + cyan outline; враги: стилизованные маски; конусы зрения: magenta.
- Нейтрализация: глитч-неон dissolve (не кровь).
- UI: жёсткая сетка пейджера, моноширинные цифры миссии, минимум панелей.

### 7.2. Насилие и возрастной рейтинг (критично для модерации)

**Продуктовое решение по умолчанию: 12+.**

Обязательные ограничения визуала:
- враги — явно вымышленные стилизованные человекоподобные силуэты / маски;
- нет реалистичной крови, ран, внутренностей, луж, страданий;
- «нейтрализация» = вспышка неона / глитч / растворение / отключение;
- оружие стилизовано, без фотореалистичных моделей;
- нет насилия над детьми и животными (робопёс = механизм);
- нет политики, религии, наркотиков как геймплей-центра;
- нет мата (требование 8.2.4).

Если позже нужен более жёсткий тон — отдельная ветка контента под **16+** только после юридической/модерационной оценки. На старте выгоднее охват 12+.

### 7.3. Аудио

- 6–10 боевых треков loop-friendly;
- отдельный «death sting» 0.2 сек;
- толстый Foley шагов/дверей — игрок слышит угрозу раньше, чем видит;
- обязателен mute в настройках (рекомендация 6.2);
- при `visibilitychange` / blur — стоп звука (требование 1.3);
- при fullscreen/RV рекламе — пауза геймплея и звука (4.7).

Размер билда: целевой бюджет аудио ≤ 25–30 МБ сжатого VORBIS/MP3, общий архив **< 100 МБ** (1.21).

## 8. Прогрессия, удержание, экономика

### 8.1. Валюты

| Валюта | Как получить | На что тратить |
|---|---|---|
| **Импульсы** (soft) | миссии, daily, RV | расходники, реролл daily-модификатора, мелкие личины |
| **Кассеты** (premium) | S-ранги редко, IAP, иногда ивент | косметика, удобства, battle-pass |
| **Очки сигнала** (XP сезона) | любая активность | бесплатная ветка сезонного пропуска |

### 8.2. Что можно купить за донат (IAP)

Только через SDK платежей Яндекс Игр (1.4, 1.13):

1. **Отключить interstitial** (навсегда / на 30 дней) — не отключает возможность RV.
2. **Набор кассет** (несколько паков цен).
3. **Косметика:** окрасы, рамки результата, альтернативные личины-скины.
4. **Сезонный пропуск** (удобства + косметика; без pay-to-win оружия).
5. **Starter pack** (одноразовый, лучший value) — кассеты + скин + 3 расходника.

Запрещено:
- продавать прохождение сюжетных уровней;
- гейтить продолжение игры за RV или оплату;
- внешние платежи, ссылки на донат вне SDK;
- лутбоксы с неочевидными шансами (избегать; если делать — только косметика и прозрачные правила).

### 8.3. Rewarded video — допустимые награды

RV **только по желанию игрока**, с явным текстом «Смотреть → получить X» (4.5, 4.5.1, 4.5.2):

| Точка | Награда | Почему ок |
|---|---|---|
| После поражения | «Повтор без потери комбо-множителя» | бонус, играть можно и так |
| После победы | «x2 Импульсы» | классика, высокий opt-in |
| В миссии (опционально) | «Показать конусы зрения 10 сек» | не обязателен для прохождения |
| Мета | «Доп. попытка daily» | суточная ценность |
| Магазин | «Бесплатная кассета раз в N часов» | sink/source баланс |

Нельзя: «посмотри рекламу, чтобы продолжить сюжет» как единственный путь.

### 8.4. Interstitial

Показ **только в логических паузах** (4.4):
- между миссиями (после экрана результатов, по кнопке «Далее»);
- при возврате в хаб из миссии;
- не чаще, чем позволяет платформа (частоту контролирует Яндекс);
- **не** по `setInterval` во время боя;
- **не** сразу при первом запуске до `LoadingAPI.ready` и первого осмысленного действия.

Рекомендуемый UX-порядок после миссии:
1. Результаты + ранг (1.5–2.5 сек эмоции).
2. Кнопка «Забрать награду».
3. Попытка interstitial.
4. Хаб / следующая миссия.

### 8.5. Sticky banner

- Включить в консоли.
- На экране боя: по возможности скрывать через API, если сильно режет поле (особенно portrait).
- На хабе/результатах — показывать.
- UI всегда учитывает safe area баннера.

### 8.6. LiveOps ритм

| Каденция | Событие |
|---|---|
| Ежедневно | Daily Signal + free RV кассета |
| Еженедельно | Weekly Contract + таблица лидеров |
| Раз в 2 недели | мини-ивент на скин |
| Раз в 4 недели | контент-патч (5–8 миссий или новый враг) |
| Сезон 6–8 недель | battle pass |

## 9. Монетизация: модель прибыли

### 9.1. Формула дохода

```
Revenue ≈
  (DAU × sessions × interstitial_fill × eCPM_i / 1000)
+ (DAU × rewarded_views × eCPM_r / 1000)
+ (DAU × sticky_impressions × eCPM_s / 1000)
+ (DAU × IAP_conversion × ARPPU)
```

### 9.2. Целевая экономика сессии (дизайн)

Средняя сессия 8 минут:
- 3–6 завершённых миссий (с рестартами внутри);
- 2–4 логические паузы → 1–3 interstitial (сколько отдаст платформа);
- 0–2 RV по желанию.

### 9.3. Антифрод и UX рекламы

- Не показывать рекламу mid-input в бою.
- Пауза input + audio onOpen, resume onClose.
- Сохранять прогресс до показа рекламы.
- Не имитировать рекламные блоки своими модалками (1.16).
- Не модифицировать внешний вид блоков РСЯ.

### 9.4. Что продаёт лучше в этом жанре

1. **Remove ads** — для skill-сегмента, который рестартит часто и бесится на паузы.  
2. **Cosmetics / flex** — рамка S+, анимация смерти врага «глитч-золото».  
3. **Comfort** — x2 soft за RV уже бесплатно; платный комфорт = больше расходников отвлечения.  
4. Не продавать силу, которая проходит уровень за игрока.

## 11. Техническая архитектура (рекомендация)

### 11.1. Стек

Для Яндекс Игр оптимально:

- **Phaser 3** или **PixiJS + собственный цикл** — 2D top-down, контроль размера;
- TypeScript;
- сборка Vite;
- локальные JSON миссий;
- Yandex Games SDK wrapper (`/src/platform/yandex.ts`).

Альтернатива: Unity WebGL — хуже по весу и холодному старту; брать только если команда уже на Unity и укладывается в 100 МБ + быстрый load.

### 11.2. Критические модули

1. `Boot/SDK` — init, locale, player, ready.
2. `SaveService` — localStorage + cloud player data.
3. `MissionRuntime` — AI, vision cones, combat, restart.
4. `InputRouter` — touch/desktop remap.
5. `AdsService` — fullscreen/rewarded/sticky + pause bridge.
6. `PurchaseService` — catalog, buy, consume, restore.
7. `AudioService` — buses, ducking, visibility policy.
8. `Analytics` — in-house events + возможности платформы.

### 11.3. Сохранения

Сохранять сразу после:
- завершения миссии;
- изменения настроек;
- покупки / получения RV-награды;
- открытия личины.

Структура сейва минимальна (слоты миссий, валюта, настройки, косметика, daily timestamp).

Гость: local progress.  
После авторизации: merge cloud ← max progress (анти-откат аккуратный).

### 11.4. Производительность

- Цель: 60 FPS на Snapdragon 7-series / 30+ на слабых.
- Object pooling для pullets/FX.
- Vision cone — не per-pixel, а sector checks + tile LOS.
- Рестарт уровня = reset state, не unload сцены.
- Первый input < 3 сек после `ready` на 4G.

## 14. Нарратив (кратко)

### Тон

Холодный, ритмичный, немного абсурдный. Игрок не «герой», а функция Сигнала. К концу главы 3 раскрывается: сигналы генерирует не человек, а система города, которая чистит «сбои». Финал — выбор: выключить Сигнал или стать его постоянным оператором (нью-гейм+ флаг).

### Почему сюжет вторичен

На удержание и деньги в этом жанре работает **мастерство + саунд + короткий цикл**, а не кат-сцены. Сюжет — пряность, не скелет.

## 17. Баланс сложности

### Кривая

- Миссии 1–3: почти невозможно не понять правила.
- 4–7: вводим щитовика и шум.
- 8–12: множественные конусы, развилки.
- Дальше: композиция из известных паттернов, не новые правила каждый раз.

### Философия fail

Смерть должна читаться: «меня увидели слева», а не «рандом».  
Replayability строится на знании уровня, не на RNG урона.

### Помощь без разрушения престижа

- RV-подсветка конусов.
- Опциональный режим «Тренировка» без рангов и без наград.
- Подсказка маршрута после N смертей подряд (не рекламная обязаловка; можно за soft currency).

## 21. Экономика контента уровней

Каждая миссия проектируется как **3 слоя**:

1. **Safe route** — медленный обход, доступен новичкам.
2. **Aggression route** — быстрее, выше риск, нужен для S.
3. **Style route** — необязательные отвлечения/комбо для S+.

Если у миссии нет хотя бы двух маршрутов — она слабая, переделать.

Чеклист уровня перед мержем:
- [ ] проходим без огнестрела;
- [ ] проходим за < 40 сек спидраном;
- [ ] первая смерть обучает;
- [ ] нет тупиков без телеграфа;
- [ ] читается на маленьком экране;
- [ ] не ломается от sticky banner safe area.

## 24. Рекомендации «как увлечь и заработать» (сжатый playbook)

1. **Первые 60 секунд священны:** бой, смерть, рестарт, маленькая победа.
2. **Сделайте рестарт наркотиком**, а не наказанием.
3. **Продавайте эмоцию ранга S**, не силу.
4. **Рекламу встраивайте в дыхание** между миссиями, не в лёгкие.
5. **Каждый день давайте повод зайти** (daily signal).
6. **Слушайте отзывы про управление** первую неделю — это №1 причина оценок <3.
7. **Не копируйте gore Hotline** — на Яндекс Играх выигрывает стилизованный ритм-экшен с честной сложностью.
8. **Держите рейтинг:** быстрые фиксы багов важнее новой главы.

## 25. Приложение A — Пример конкретной миссии «Плат-03»

**Цель:** забрать кейс, выйти.  
**Карта:** 3 комнаты + коридор-крест + задняя лестница.  
**Враги:** 2 патрульных, 1 щитовик у кейса, 1 дрогган в узком входе.  
**Обучение:** игрок видит, что фронтальный заход в дверь = смерть от дробовика; обход через лестницу + бросок бутылки открывает окно.  
**S-условие:** не поднимать тревогу.  
**RV-бонус на death screen:** «Показать последний конус, который вас спалил» (обучение, не пропуск).  
**Длина целевого успешного забега:** 25–45 сек.

## 27. Финальная продуктовая формулировка

**«СИГНАЛ»** — это мобильный top-down combat-arcade для Яндекс Игр, где игрок в неоновых коротких рейдах учится на мгновенных смертях, гоняется за S-рангом и смотрит рекламу только между забегами, а платит за комфорт и статус — не за право играть.
