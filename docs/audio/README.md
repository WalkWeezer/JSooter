# Аудио-референсы «Неонтрон: Ночной штурм»

Процедурно сгенерированные лупы для диздока и прототипа.  
Формат: **MP3** (для веба) + **WAV** (мастер).

| Трек | Файл | BPM | Назначение |
|---|---|---|---|
| Hub / Night Ops | `neontron-hub-loop.mp3` | 92 | хаб, пейджер, брифинг, выбор миссии |
| Combat Assault | `neontron-combat-loop.mp3` | 128 | бой, зачистка этажа, погоня за S-рангом |

## Характер звука

- **Hub:** тёмный synth-pad, мягкий пульс, арпеджио, лёгкий delay — «ночной контракт»
- **Combat:** driving bass, kick/snare, lead stabs — «штурм этажа»

## Использование в билде

- Лупы должны быть **seamless** в проде (кроссфейд или точная длина бара)
- При рекламе и сворачивании вкладки — **стоп звука** (требование Яндекс Игр 1.3, 4.7)
- Обязательный **mute** в настройках (рекомендация 6.2)
- Бюджет аудио в архиве: ≤ 25–30 МБ сжатого

## Следующий шаг

Заменить референсы на финальные треки композитора в том же темпе и тональности, чтобы не ломать синхронизацию геймплея с ритмом.
