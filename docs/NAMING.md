# Нейминг: шортлист названий

Рабочее название в GDD сейчас — **«СИГНАЛ»**. Ниже — более броские кандидаты под Яндекс Игры: запоминаемость, звучание вслух, отсылки к популярным IP **без прямого копирования trademark**.

Критерии отбора:
- коротко и «щёлкает» в голове;
- хорошо выглядит на иконке / обложке;
- есть хук (телефон, маска, неон, район, one-hit);
- не конфликтует с Hotline Miami / GTA / другими брендами напрямую;
- уникально ищется в каталоге;
- без слов «игра» / «game».

---

## Топ-рекомендации

### 1) АЛЁ  ← главный кандидат
**Почему работает:** 3 буквы, невозможно забыть, очень по-русски, абсурдный юмор в духе Hotline. Отсылка к телефонному ритуалу («горячая линия»), но это не чужой бренд.

- Произношение: резко, как удар битой  
- Карточка: «АЛЁ — ночные зачистки по сигналу пейджера»  
- Риск trademark: низкий  
- Риск «слишком абстрактно»: средний → лечится подзаголовком в описании

**Подзаголовок в сторе (не в названии):** *Не тот номер. Один удар — и снова гудки.*

---

### 2) НЕ ТОТ НОМЕР
**Почему работает:** готовый мем-хук, сразу понятен сюжетный заход, отсылка к неправильным звонкам Hotline Miami без копирования названия.

- Отлично для промо и превью  
- Чуть длиннее для иконки  
- Риск: низкий  

Хорош как **полное название**, если «АЛЁ» покажется слишком коротким.

---

### 3) КОРОТКИЕ ГУДКИ
**Почему работает:** жутко-знакомая русская телефонная формула. Звучит как приговор. Сильный локальный колорит для Яндекс Игр.

- Атмосферно и уникально  
- Длинновато на обложке → можно сокращать визуально до «ГУДКИ»  
- Риск: низкий  

---

### 4) ПЕЙДЖЕР 88
**Почему работает:** объект-иконка жанра + число «как из 80-х / Vice / outrun». Легко сделать логотип из самого пейджера.

- Отсылки: Hotline pager, Vice City «80s», synthwave  
- Риск: низкий (число 88 в RU иногда чувствительно — **проверить** перед фиксацией; при сомнении взять **ПЕЙДЖЕР 84** или **ПЕЙДЖЕР**)

---

### 5) HOLD.LINE
**Почему работает:** английский стиль «indie hit», визуально модно (точка в середине), прямая смысловая рифма к hotline без слова Hotline.

- Хорошо для EN/RU каталога  
- На аудитории Яндекса может проиграть чисто русскому названию  
- Риск: низкий–средний (идея «line», не бренд)

## Осторожно / лучше не брать

| Вариант | Почему нет |
|---|---|
| Hotline / Хотлайн / Hotline Night | прямой конфликт с IP Dennaton |
| Miami / Vice / Вайс Сити | слишком близко к Rockstar / Hotline |
| GTA-style названия с «Grand / Theft» | лишний риск и модерация |
| Кровавый / Blood / Gore в названии | бьёт по 12+ и промо |
| СИГНАЛ (текущее) | нормально, но блекло и занято в быту/других продуктах |

## Комбо-схемы (название + подзаголовок)

Иногда лучше короткое имя + жирный tagline в описании:

1. **АЛЁ** — *Не тот номер*  
2. **ГУДКИ** — *Один удар. Снова гудки.*  
3. **ПЕЙДЖЕР** — *Ночные контракты*  
4. **HOLD.LINE** — *Clear the floor*  
5. **СБРОС** — *Умер — начни идеально*

---

## Проверка перед финалом (обязательно)

1. Поиск в каталоге Яндекс Игр — точное и похожие названия.  
2. Поиск товарных знаков RU/международных по ключевому слову.  
3. Произнести вслух 10 раз и показать 5 людям без контекста: что представили?  
4. Нарисовать лого на иконке 128×128: читается ли?  
5. Проверить домен/сообщество «Яндекс Игры + название» для соцсетей (треб. платформы к внешним ссылкам учитывать отдельно).

---

## Рекомендация продакта

**Зафиксировать рабочим названием: `АЛЁ`.**  
В описании и промо использовать хук **«Не тот номер»**.

Почему:
- максимальная запоминаемость на RU-рынке;
- телефонная ДНК жанра без чужого trademark;
- короткое имя = сильный бренд на обложке;
- абсурдный тон совпадает с hotline-like фантазией;
- легко строить серию: «АЛЁ 2», ивент «АЛЁ: Порт», скины «АЛЁ: Кассета».

Если нужен более «объясняющий» вариант для стора с первого взгляда — брать **`НЕ ТОТ НОМЕР`**.
